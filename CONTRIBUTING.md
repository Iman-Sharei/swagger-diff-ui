# Contributing to swagger-diff-ui

Thanks for your interest in improving swagger-diff-ui.

## Reporting a bug

Open an issue with your Django, DRF and drf-spectacular versions, the git ref you compared against, and what you expected to see.

## Sending a pull request

1. Fork the repo and create a branch from `main`.
2. Install in editable mode: `pip install -e .`
3. Keep changes focused and add a test when you fix a bug.
4. Open a pull request that explains what changed and why.

Small fixes like typos and docs improvements are always welcome.
